ReplayVOD updates the database automatically when the new version starts.

## Before updating

Read the [release notes](https://github.com/befabri/replayvod/releases) for the versions between your current and target release. Follow any upgrade instructions, then [back up](/docs/backup/) your configuration, database, and media.

## Update

The commands below assume your checkout tracks a branch. If the installer checked out a release tag, fetch tags and check out your target release instead of running `git pull`. Review local configuration changes before switching versions.

<Tabs syncKey="platform">
  <TabItem label="macOS / Linux">

  ```bash
  cd ~/replayvod
  git pull --ff-only   # update Compose and configuration files
  docker compose --env-file server/.env --profile sqlite pull
  docker compose --env-file server/.env --profile sqlite up -d
  ```

  Use `--profile postgres` for PostgreSQL. These commands pull the image configured in your Compose file. Add `--build` to the `up` command if you build from local source.

  </TabItem>
  <TabItem label="Windows">

  Open PowerShell in the parent of your ReplayVOD directory:

  ```powershell
  Set-Location replayvod
  git pull --ff-only   # update Compose and configuration files
  docker compose --env-file server/.env --profile sqlite pull
  docker compose --env-file server/.env --profile sqlite up -d
  ```

  Use `--profile postgres` for PostgreSQL. These commands pull the image configured in your Compose file. Add `--build` to the `up` command if you build from local source.

  </TabItem>
  <TabItem label="Build from source">

  ```bash
  cd replayvod
  git pull --ff-only
  task build
  ```

  Stop the running server before replacing its binary and dashboard files, then start it with the new build.

  </TabItem>
</Tabs>

## After updating

1. Sign in and check your existing rules in **Recordings → Schedules**.
2. Open **Library → Videos** and play an existing recording.
3. Check **System → EventSub** and resolve any setup or restart message.
